# Ayub Real Estate

Premium, responsive, interactive real-estate demo for Ayub Real Estate.

## See the demo without installing anything

1. Open the repository on GitHub: https://github.com/ideaviknl-crypto/AyubRealEstate-Premium
2. Open `index.html`.
3. Click the **Raw** button, then save the page as `index.html` on your computer.
4. Double-click the saved file. It will open in your browser.

For a public URL, import this repository into Vercel, Netlify, or GitHub Pages. This first demo includes a premium customer property view, property filters, favorites, a login modal, and a property-listing CTA. Authentication, dashboards, database persistence, and real-time messaging still need to be connected to a backend.
